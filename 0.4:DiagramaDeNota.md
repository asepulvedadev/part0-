<h1> 🔄 Flujo de eventos al crear una nueva nota: </h1>
<h2> 1. Usuario interactúa con la página </h2>
<ul>
 <li> Escribe texto en el campo de entrada. </li>
 <li> Hace clic en el botón "Save". </li>
</ul>

<h2> 2. El navegador envía una solicitud POST al servidor </h2>
<ul>
  <li> POST https://studies.cs.helsinki.fi/exampleapp/new_note </li>

  <li> Datos del formulario enviados: { content: "...", date: "..." } </li>
</ul>
<h2>3. El servidor procesa la solicitud </h2>
<ul> 
  <li> Guarda la nueva nota. </li>
  <li> Devuelve una redirección: 302 Redirect a /notes. </li>
</ul>
<h2>4. El navegador sigue la redirección automáticamente </h2>
<ul>
<li> GET https://studies.cs.helsinki.fi/exampleapp/notes </li>
<li> El servidor responde con el documento HTML actualizado. </li>
</ul>
<h2>5. El navegador carga recursos adicionales </h2>
<ul>
<li> GET /main.css → CSSs </li>
<li> GET /main.js → JavaScript </li>
</ul>
<h2>6. javaScript del cliente se ejecuta</h2>
<ul>
<li> envia una solicitud para obtener los datos actualizados.</li>
 <ul>
   <li> GET /data.json. </li>
   <li>recibe todas las notas (incluida la nueva). </li>
  <ul/>
<li> Ejecuta la función callback que renderiza las notas en la página. </li>
</ul>
