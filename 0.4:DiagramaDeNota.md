<h1> 🔄 Flujo de eventos al crear una nueva nota: </h1>
<h2> 1. Usuario interactúa con la página </h2>
<ul>
 <li> Escribe texto en el campo de entrada. </li>
 <li> Hace clic en el botón "Save". </li>
</ul>

<h2> 2. El navegador envía una solicitud POST al servidor </h2>
<ul>
  <li> POST https://studies.cs.helsinki.fi/exampleapp/new_note </li>

  <li> Datos del formulario enviados: { content: "...", date: "..." } </li>
</ul>
<h2>3. El servidor procesa la solicitud </h2>
<ul> 
  <li> Guarda la nueva nota. </li>
  <li> Devuelve una redirección: 302 Redirect a /notes. </li>


</ul>
El navegador sigue la redirección automáticamente

GET https://studies.cs.helsinki.fi/exampleapp/notes

El servidor responde con el documento HTML actualizado.

El navegador carga recursos adicionales

GET /main.css → CSS

GET /main.js → JavaScript
