  <h1>🧠 SPA: Carga de la Aplicación de Notas</h1>
  <h2>Ruta: <code> /spa </code></h2>

  <ol>
    <li>El usuario accede a <code> https://studies.cs.helsinki.fi/exampleapp/spa </code>.</li>

  <li>El navegador solicita el documento HTML base (shell de la SPA):
      <br><code>GET /spa</code> → el servidor responde con un HTML básico.</li>

  <li>Se cargan los recursos estáticos necesarios:
      <ul>
        <li><code>GET /main.css</code> → estilos CSS</li>
        <li><code>GET /spa.js</code> → lógica de la aplicación en JavaScript</li>
      </ul>
    </li>

  <li>El navegador ejecuta <code>spa.js</code>, que contiene la lógica del lado del cliente.</li>

  <li>Se realiza una solicitud asincrónica para obtener las notas existentes:
      <br><code>GET /data.json</code> → el servidor responde con un arreglo JSON de notas.</li>

   <li>La aplicación renderiza dinámicamente las notas en el DOM **sin recargar la página**.</li>
  </ol>

  <p><strong>Conclusión:</strong> la SPA se carga una vez y luego gestiona la interfaz y el contenido dinámicamente usando JavaScript y peticiones fetch.</p>
